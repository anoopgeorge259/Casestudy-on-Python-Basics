# Python Basics Case Study

This repository contains two Python programs developed as part of an assignment for the Executive Program in Advanced AI/ML.

## Programs Included

### 1. Bank Account Manager
A simple banking system simulation that allows users to:
- Deposit money
- Withdraw money
- Check account balance

Concepts used:
- Variables and data types
- Conditional statements
- Functions
- Loops

### 2. Weather Data Analyzer
A Python program that analyzes weather data for a given region.

Features:
- Takes user input for region, temperature, and humidity
- Stores data in lists
- Calculates average temperature and humidity
- Determines weather conditions such as sunny, rainy, or cloudy

Concepts used:
- Variables
- Lists
- Conditional statements
- Functions
- Loops
